# Kangaroo Express Mobile App

Vercel-ready installable PWA for **Kangaroo Express — Making Life Easier.**

- Uses the real 23-product Kangaroo Express catalogue and local product photography.
- Uses the supplied Kangaroo Express logo.
- Includes four original app-specific promotional flyers; mother-website promotional banners are not used.
- WhatsApp ordering includes product links and direct public image links.
- Kampala delivery is shown as free.
- Payment choices: MTN Mobile Money, Airtel Money and Cash on Delivery.
